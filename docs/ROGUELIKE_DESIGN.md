# Azeroth Survivors 增强版：构筑与联动设计

原版的问题：升级只有"伤害 +30%、冷却 -7%、范围 +8%"，技能之间互不影响，学了就不能忘，
打到后期每局都一样。这一版在原有的自动施法、升级三选一、Boss 节奏上，加了一整层**构筑系统**，
核心是**联动**。所有名字、机制、物品、特效都用魔兽世界里玩家早就熟悉的东西：
天赋树、31 点天赋、附魔、团队副本装备、经典 Debuff。游戏内文字是英文（游戏字体只有拉丁字母），
下面附上国服常用译名。

## 参考了谁、拿了什么

| 游戏 | 借鉴的设计 | 在本作中的样子 |
|---|---|---|
| 吸血鬼幸存者 | **进化**：两样东西练满后合成更强的武器 | **合体技**：两个满级技能（或满级技能 + 传说装备）合成新技能，如暴风雪 + 烈焰风暴 → 流星 |
| 魔兽世界本身 | **天赋树**与 31 点天赋 | 每职业 3 系天赋；首个天赋就是**专精**，会改变初始技能；点满一系习得**深层天赋技能** |
| 哈迪斯 Hades | 神祇祝福带**状态效果**；**双神祝福** | 每种伤害类型留下经典 Debuff；**混合天赋**需要两种伤害类型 |
| 哈迪斯 | 武器**形态**改变打法 | **附魔**：改变单个技能的行为（风怒、多重射击、腐蚀之种……） |
| 杀戮尖塔 | **遗物**、Boss 遗物强但有代价、删牌 | 精英与 Boss 掉**装备**（需求/贪婪三选一）；诅咒装备；**遗忘**技能 |
| 吸血鬼幸存者 / 土豆兄弟 | 重掷 / 放逐、以血换攻 | R 重掷、B 放逐；诅咒天赋（奥术强化、死亡之愿） |

## 一、伤害类型与经典 Debuff（联动的地基）

每个技能都有伤害类型（按 WoW 原设），**所有命中都会留下 Debuff**，不需要任何天赋：

| 伤害类型 | Debuff | 效果 |
|---|---|---|
| 冰霜 | 冬天之寒 Winter's Chill | 每层减速 6%；5 层**冰冻** 1.5 秒（Boss 免疫）；冰冻的敌人受到所有伤害 **+40%** |
| 火焰 | 点燃 Ignite | 每次火焰命中让点燃变旺（最多为单次命中的 20%/秒），暴击加倍 |
| 自然 | 震击 Shock | 3 层时迸出**闪电链**：本次伤害的 35% 跳到附近 2 个敌人 |
| 暗影 | 暗影之波 Shadow Weaving | 目标身上每有一个持续伤害，暗影伤害 +8%（最多 5 个） |
| 神圣 | 审判 Judgement | 受到物理伤害 +15%；死亡时治疗你 1 点 |
| 物理 | 破甲攻击 Sunder Armor | 每层让敌人受到所有伤害 +3%（5 层） |
| 奥术 | 奥术充能 Arcane Charges（在你身上） | 每次奥术施法 +1 层（4 层，8 秒），每层所有伤害 +4% |

## 二、天赋树（每职业 3 系）

升级时出现天赋卡。**第一次升级必定是"选择专精"**，三张卡各代表一系：

- **第 1 层：专精天赋**。选了哪系，初始技能就变成那一系的招牌技能。
  比如**暗影牧师**：惩击 → 暗言术：痛；**火焰法师**：寒冰箭 → 火球术；**狂怒战士**：顺劈斩 → 旋风斩。
  可以再点别的系的专精，做混搭。
- **第 2 层**：需要本系先点 1 点。
- **深层天赋（31 点天赋）**：本系两个天赋都点了以后出现橙卡，**习得一个新技能**，不占技能槽。

| 职业 | 天赋系（专精后初始技能 → 深层技能） |
|---|---|
| 战士 | 武器（英勇打击 → 致死打击）· 狂怒（旋风斩 → 嗜血）· 防护（雷霆一击 → 盾牌猛击） |
| 圣骑士 | 神圣（驱邪术 → 神圣震击）· 防护（奉献 → 神圣之盾）· 惩戒（审判 → 命令圣印） |
| 猎人 | 野兽控制（多重射击 → 狂野怒火）· 射击（奥术射击 → 瞄准射击）· 生存（毒蛇钉刺 → 翼龙钉刺） |
| 盗贼 | 刺杀（剔骨 → 伏击）· 战斗（邪恶攻击 → 剑刃乱舞）· 敏锐（凿击 → 出血） |
| 牧师 | 戒律（惩击 → 星辰碎片）· 神圣（神圣之火 → 神圣新星）· 暗影（暗言术：痛 → 精神鞭笞） |
| 萨满 | 元素（闪电箭 → 地震术）· 增强（闪电之盾 → 风暴打击）· 恢复（灼热图腾 → 治疗链） |
| 法师 | 奥术（奥术飞弹 → 奥术冲击）· 火焰（火球术 → 炎爆术）· 冰霜（寒冰箭 → 寒冰箭雨） |
| 术士 | 痛苦（腐蚀术 → 生命虹吸）· 恶魔学识（暗影箭 → 灵魂之火）· 毁灭（献祭 → 燃烧） |
| 德鲁伊 | 平衡（月火术 → 枭兽形态）· 野性战斗（横扫 → 野性冲锋）· 恢复（愤怒 → 迅捷治愈） |

各系的天赋用该职业的原版天赋名：碎冰、点燃、燃烧、奥术心智、深度伤口、乱舞、
无情打击、精神分流、闪电掌握、元素掌握、月怒……效果是机制性的（例如碎冰：4 层就冰冻，冰冻 +100%）。
致死打击、神圣震击、瞄准射击、剑刃乱舞、神圣新星、炎爆术在原版里就是天赋技能，
所以从基础技能池移走，只能通过天赋树获得。

**通用天赋**（任何职业）：节能施法、临界质量、血之狂乱、吸血鬼的拥抱、孤狼（每个空技能槽 +15%）、
元素精准（每多一种伤害类型 +6%）、复苏之风、永冻（控制时间 +50%）。
**诅咒天赋**：奥术强化（+45% 伤害 / -35% 血量）、死亡之愿、英雄难度（+40% 经验 / 敌人更肉）。

**混合天赋**（橙卡，需要两种伤害类型的技能）：霜火、暗影烈焰、冰封武器、苦修、艾露恩之怒、
灼热之光、霜之哀伤、奥金斧、毁灭之锤、天灾入侵（持续伤害在受害者死亡时扩散）。

## 三、合体技（练满两个核心技能后进化）

两个技能都升到满级（8 级），下一次升级**必定出现**金色合体卡，学会一个更强的新技能，
不占技能槽，原来两个技能保留。合体技本身也能继续升级。

| 合体技 | 配方 |
|---|---|
| 流星 Meteor（冰火双属性） | 暴风雪 + 烈焰风暴 |
| 冰霜冲击 Frost Blast（克尔苏加德） | 寒冰箭 + 冰霜新星 |
| 火球齐射 | 火球术 + 炎爆术 |
| 剑刃风暴 | 旋风斩 + 横扫攻击 |
| 震荡波 | 致死打击 + 斩杀 |
| 十字军打击 | 愤怒之锤 + 审判 |
| 爆炸射击 | 多重射击 + 爆炸陷阱 |
| 冲动 Adrenaline Rush | 邪恶攻击 + 剑刃乱舞 |
| 噬灵瘟疫 | 暗言术：痛 + 精神鞭笞 |
| 火焰新星图腾 | 灼热图腾 + 熔岩图腾 |
| 球状闪电 | 闪电箭 + 闪电链 |
| 暗影箭雨 | 暗影箭 + 腐蚀术 |
| 地狱火 Inferno | 火焰之雨 + 地狱烈焰 |
| 星辰坠落 Starfall | 月火术 + 星火术 |
| **拉格纳罗斯之怒**（任何职业） | 萨弗拉斯 + 任意满级火焰技能 |
| **闪电云**（任何职业） | 雷霆之怒 + 任意满级自然技能 |
| **堕落之血**（任何职业） | 哈卡之心 + 任意满级暗影技能 |

装备也参与合体：锻出萨弗拉斯或雷霆之怒、拿到哈卡之心，就开启跨职业的合体技。

## 四、附魔（改变单个技能的打法）

技能 2 级开 1 个附魔槽，5 级第 2 个，8 级第 3 个。只出现适合该技能的附魔：

- 飞弹类：**多重射击**（击杀分裂 2 发）、**横扫攻击**（+2 目标）、**气定神闲**（每 4 次 3 倍必暴）、**斩杀**（30% 血以下双倍）
- 近战：**生命偷取**（每次命中回 1% 血）
- 范围类：**风怒**（再放一次，60% 伤害）、**光环掌握**（+40% 范围）、**清算**（被打时立刻释放）
- 地面类：**惩罚光环**（法阵跟着你走）、**镜像**（同时放第二个）
- 持续伤害：**腐蚀之种**（死亡时扩散给 2 个）、**吸取生命**（持续伤害吸血 20%）
- 链类：**叉状闪电**（+3 跳且不衰减）；自身类：**圣洁光环**（施放时 8 码神圣伤害）；图腾：**图腾掌握**
- 通用：**暴怒**（每次击杀 +1% 伤害，最多 +80%）、**元素诅咒**（Debuff 施加两次）、**自然迅捷**（冷却 -25%）
- **武器附魔 ×6**，给技能加第二种伤害类型，+10% 伤害：冰寒、烈焰武器、邪恶武器、致命毒药、十字军、卓越巫师之油。
  这是跨类型联动的钥匙：给暴风雪附魔烈焰武器，就能拿到"霜火"混合天赋。

## 九、数值与难度

- 构筑层加成大多是乘法叠加，但每项 Debuff 有层数上限。
- **吸血和回血不设上限**：神装构筑可以无限续航，这是玩家应得的奖励。
- 敌人后期血量曲线 ×3.0、伤害 ×2.3（二次曲线，前期几乎不变）。散装构筑后期吃力，
  联动成型（天赋树深层技能、合体技）才打得动：这就是挑战。
- 精英是中期检定点；诅咒选项给敢赌的人更高上限。

## 十、构筑示例

- **冰火法师**：冰霜专精 → 寒冰箭 + 冰霜新星冻住怪群 → 火球打冰冻目标 +40% → "霜火" → 两者练满合成**冰霜冲击**；
  再练暴风雪 + 烈焰风暴，合成**流星**。
- **暗影牧师**：暗影专精，惩击变暗言术：痛 → 暗影之波 + 精神分流 → 深层技能**精神鞭笞** → 与暗言术：痛合成**噬灵瘟疫**，
  吸血无上限，越打越肉。
- **风暴萨满**：元素专精，闪电箭 + 闪电链叠震击 → 闪电掌握 → 合成**球状闪电**；锻出雷霆之怒后再得**闪电云**。
- **狂怒战士**：狂怒专精，旋风斩开局 → 乱舞 → 深层技能**嗜血**（吸血） → 旋风斩 + 横扫攻击合成**剑刃风暴**。

`TALENTS` 里用 `tt(..)` 加该系的两个天赋。

## 专精主动技能：Q 爆发 / E 减伤 / F 位移

选择专精（第一次升级）时同时学会三个**手动释放**的技能，什么时候按完全由玩家决定，它们从不自动施放。代码在 `crates/benilla-app/src/survivors/actives.rs`，游戏和模拟器调用同一份 `Run::activate`（对角色的效果）与 `actives::touch`（对每个敌人的效果）。

设计原则：**爆发技必须撬动该专精的核心机制**，而不是单纯加伤害。引爆类爆发会消耗掉敌人身上的状态，所以要先铺状态、再找时机按，这就是操作上的策略点。

| 职业 | 专精 | Q 爆发（与核心机制的联动） | E 减伤 | F 位移 |
|---|---|---|---|---|
| 战士 | 武器 | 鲁莽：10 秒必暴击（每次暴击触发深伤、乱舞） | 反击风暴：反伤 + 减伤 25% | 冲锋 |
| 战士 | 狂暴 | 死亡之愿：怒气瞬间填满 → 立刻激怒；伤害 +25%，受伤 +15% | 狂暴之怒：每秒回 4% 血 | 拦截（击晕 3 秒） |
| 战士 | 防护 | 震荡猛击：10 码内按每层破甲造成伤害并击晕 | 盾墙：减伤 70% | 刺耳怒吼：减速 60% |
| 圣骑士 | 神圣 | 神恩术：20 码内每个被审判的敌人受圣光打击，每个回 1% 血；8 秒必暴击 | 保护祝福：无敌 5 秒 | 自由祝福 |
